# Einfach kochen

Funktionaler Web-Prototyp für einen stark reduzierten, konsequent barrierefreien Rezeptablauf:

1. deutsches Wochenmenü
2. Rezeptdetails
3. Zutaten mit Menge und konkreter Verpackungsbeschreibung
4. Kochmodus mit jeweils einem Kochschritt

Der Prototyp enthält bewusst keine Anmeldung, Bestellung oder Boxverwaltung.

## Lokal starten

```bash
npm install
npm run dev
```

## Qualitätsmerkmale

- semantische HTML-Struktur und nachvollziehbare Überschriftenhierarchie
- vollständige Tastaturbedienung und sichtbare Fokusmarkierung
- Sprunglink zum Hauptinhalt
- Fokusführung und Live-Ansagen bei Ansichts- und Schrittwechseln
- beschreibende Alternativtexte für alle Rezeptbilder
- responsive Darstellung und Unterstützung reduzierter Bewegung
- große Bedienziele und kontrastreiche Gestaltung
- konkrete Erkennungsmerkmale für Zutatenverpackungen

Die Ergebnisse der visuellen Prüfung stehen in `design-qa.md`.
